# davidtucker/homebrew-tap

Homebrew tap for [envhaul](https://github.com/davidtucker/envhaul), a CLI that hauls config and secrets from AWS into `.env` files.

## Install

```sh
brew install davidtucker/tap/envhaul
```

Upgrade with `brew upgrade envhaul`. Shell completions and the man page are installed too.

## About this repository

The files here are generated by envhaul's release pipeline ([GoReleaser](https://goreleaser.com)) on every stable release. Please don't edit them by hand; changes are overwritten by the next release.

Report problems in the [envhaul repository](https://github.com/davidtucker/envhaul/issues). Every release is signed and has build provenance; see [verifying releases](https://davidtucker.github.io/envhaul/security/#verifying-releases).
